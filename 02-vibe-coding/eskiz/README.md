# Эскизы экранов

- `eskiz-ekranov-v1.png` (09.11.2026): первый эскиз трёх экранов (главная «Сегодня», «Как у меня дела», ИИ-помощник и заявка). Сделан Claude по запросу Роберта «сделай картинку как это будет выглядеть»: HTML-макет (`eskiz-ekranov-v1.html`), снимок через Playwright. Шрифт Manrope (OFL), иконки нарисованы вручную в SVG. Все данные вымышленные.
- `eskiz-ekranov-v2-apple.png` (09.11.2026): те же три экрана в стиле Apple/iOS по просьбе Роберта «сделай в стиле apple». Крупные заголовки, сгруппированные списки, системные цвета iOS, полупрозрачная панель вкладок. Шрифт Inter (OFL) вместо SF Pro (у SF Pro нет свободной лицензии), иконки свои в SVG, без символов и логотипов Apple.
- `eskiz-ekranov-v3-zhidkoe-steklo.png` (09.11.2026): стиль «жидкое стекло» (как Liquid Glass в iOS 26) по просьбе Роберта: v2 «не то, хочу как новое оформление на айфонах». Полупрозрачные стеклянные карточки (backdrop-filter blur + saturate, световой блик по краю) поверх цветного размытого фона, парящая панель вкладок-капсула и отдельная круглая кнопка ИИ-помощника. Шрифт Inter (OFL), иконки свои.
- `eskiz-ekranov-v4.png` (09.11.2026): v3, исправленный по скилу UI UX Pro Max (`.claude/skills/ui-ux-pro-max`, стиль `liquid-glass`). Правило скила: стекло только у навигации и кнопок, контент на отдельном плотном слое, контраст текста от 4.5:1, запасной непрозрачный вид для «уменьшить прозрачность». Поэтому карточки стали плотнее и читаемее, стекло осталось у меню, кнопок и переключателя.
- `eskiz-ekranov-v5-puzyr.png` (09.11.2026): Роберт: v4 хуже, нужен «зеркальный, мыльно-пузырный» эффект. Вернули стекло на все карточки (как v3) и добавили: радужный край (conic-gradient), блики сверху слева и снизу справа, радужный перелив по диагонали, цветную внутреннюю подсветку краёв, преломление фона SVG-фильтром (feDisplacementMap в backdrop-filter, работает в Chrome/Android; в Safari будет без искажения, только размытие). Отступили от правила UI UX Pro Max «стекло только у навигации» по решению Роберта, читаемость текста проверим при сборке.
- `eskiz-ekranov-v6.png` (09.11.2026): переделка по разбору Роберта из 7 пунктов (стекло на пустом фоне, пятна под текстом, цвета спорят со смыслом, радуга на всём, разный фон на экранах, несерьёзный тон, пустота внизу и мелкие подписи). Что сделано: стекло только у нижней панели, кнопки помощника, переключателя и верхних кнопок; карточки плотные белые; один спокойный фон на всех экранах (светло-серый с лёгким синим сверху); фирменный цвет один (синий доверия #1f4fd8); оранжевый/зелёный/красный только как сигналы; выделена рамкой только ближайшая пара, предупреждение про аудиторию с плашкой и полосой; серый текст темнее (#555b68, контраст > 6:1); подписи вкладок 11 px, неактивные иконки темнее; добавлены объявление деканата и ещё одна дисциплина, чтобы не было пустоты.
- `eskiz-ekranov-v7.png` (09.11.2026): Роберт: «ты убрал эффект жидкого стекла». В v6 за стеклом было пусто, поэтому его не видно. В v7 контент уходит под панель и кнопку помощника, стекло сильнее: меньше белой заливки, преломление (SVG-линза), яркий блик по краю, лёгкая радужная подсветка только по краям панели и кнопок. Неудачная попытка внутри v7: синяя карточка под панелью сделала подписи вкладок нечитаемыми, заменили на белую. Вывод: в статичной картинке стекло на светлом интерфейсе заметно слабо, на сайте оно видно при прокрутке.
