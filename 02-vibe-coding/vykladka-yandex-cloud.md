# Выкладка «Цифрового деканата» в Yandex Cloud

Схема без секретов: GitHub Actions после каждого пуша собирает Docker-образ сайта и кладёт его в GitHub Container Registry (`ghcr.io/hfuvoo-art/dekanat`). Виртуальная машина в Yandex Cloud при создании сама ставит Docker и запускает сайт, Caddy (HTTPS) и watchtower, который раз в 5 минут забирает свежую версию. Настройки машины: `server/cloud-init.yaml`.

## Действие 1. Открыть образ сайта (GitHub, 1 минута)
После первой сборки (вкладка Actions → publish-dekanat, зелёная галочка):
[настройки пакета dekanat](https://github.com/users/hfuvoo-art/packages/container/dekanat/settings) → внизу «Change visibility» → **Public** → ввести `dekanat` → подтвердить.
Без этого сервер не сможет скачать образ. В образе только код сайта и вымышленные данные, ключей там нет.

## Действие 2. Создать машину (Yandex Cloud, 5 минут)
[Консоль](https://console.yandex.cloud) → Compute Cloud → «Создать ВМ»:
1. Образ: **Ubuntu 24.04 LTS**.
2. Вычислительные ресурсы: 2 vCPU, гарантированная доля 20 %, 2 ГБ RAM. Диск 20 ГБ HDD.
3. Сеть: публичный адрес **статический** (Автоматически → потом «Сделать статическим», или сразу «Список» с зарезервированным адресом).
4. Доступ: логин `dekanat`, SSH-ключ можно вставить этот (служебный, закрытый ключ к нему не хранится, нужен только чтобы форма пропустила):
   `ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIDBvgr4oyTC7ZEVGJdJaQCDxX8cuWjUoYSpV9lr+L6vh dekanat-vm`
   Если хочешь сам заходить на сервер, вставь свой ключ.
5. Раздел «Метаданные» (или «Пользовательские данные»): ключ `user-data`, значение — **весь текст** файла [`server/cloud-init.yaml`](server/cloud-init.yaml).
6. «Создать ВМ». Стоимость видна справа и списывается из гранта.

Через 3–5 минут сайт откроется по адресу `https://<IP-машины>.sslip.io`. IP виден в карточке машины.

## Потом (по желанию)
- Свой домен `.ru` (около 200 ₽ в год) вместо sslip.io: A-запись на IP, затем поменять строку `DOMAIN` в `/opt/dekanat/.env` на сервере.
- Живые ответы помощника через YandexGPT: дописать строки `LLM_*` из `app/.env.example` в `/opt/dekanat/.env` и перезапустить `docker compose up -d`. Без ключа помощник отвечает шаблонами по тем же положениям.

## Проверка перед подачей
- Открыть сайт с телефона через мобильный интернет без VPN.
- Войти тремя тестовыми аккаунтами, подать заявку, сменить её статус в кабинете учебного офиса.
- Подставить чужой номер заявки в адрес: должно быть «Страница не найдена».
