# Выкладка «Цифрового деканата» в Yandex Cloud

Схема: одна виртуальная машина, на ней Docker: сайт + Caddy (сам получает HTTPS-сертификат). Код приезжает из GitHub при каждом пуше в `main` (файл `.github/workflows/deploy-dekanat.yml`). Ключи и пароли только в секретах GitHub и в файле `.env` на сервере.

## Шаг 1. Виртуальная машина (делает Роберт, 10 минут)
1. [Консоль Yandex Cloud](https://console.yandex.cloud) → Compute Cloud → «Создать ВМ».
2. Образ: **Ubuntu 24.04 LTS**. Зона: любая `ru-central1`.
3. Ресурсы: 2 vCPU (гарантированная доля 50 %), 2 ГБ RAM, диск 20 ГБ. Сборке сайта нужно 2 ГБ памяти.
4. Сеть: публичный адрес **статический** (иначе сменится после перезапуска).
5. Доступ: логин `dekanat`, SSH-ключ. Как сделать ключ на компьютере: `ssh-keygen -t ed25519 -f dekanat_key` (появятся `dekanat_key` и `dekanat_key.pub`), в поле ВМ вставить содержимое `dekanat_key.pub`.
6. Стоимость видна справа при создании и списывается из гранта.

## Шаг 2. Домен
- Лучше: купить домен `.ru` (около 200 ₽ в год) и сделать A-запись на IP машины.
- Бесплатно: адрес `<IP>.sslip.io`, например `51.250.1.2.sslip.io`. Работает без покупки, но перед подачей проверить с телефона без VPN.

## Шаг 3. Подготовка машины (одна команда)
Зайти по SSH (`ssh -i dekanat_key dekanat@<IP>`) и выполнить:
```bash
curl -fsSL https://get.docker.com | sudo sh && sudo usermod -aG docker $USER
mkdir -p ~/dekanat && printf 'DOMAIN=<домен из шага 2>\n' > ~/dekanat/.env
exit
```

## Шаг 4. Секреты в GitHub
Репозиторий → Settings → Secrets and variables → Actions → New repository secret:
- `VM_HOST`: IP машины;
- `VM_USER`: `dekanat`;
- `VM_SSH_KEY`: всё содержимое файла `dekanat_key` (закрытый ключ).

## Шаг 5. Выкладка
Actions → deploy-dekanat → Run workflow (или любой пуш в `main`). Через 3–5 минут сайт открывается по домену.

## ИИ в помощнике (по желанию)
Дописать в `~/dekanat/.env` на сервере строки из `.env.example` (ключ YandexGPT того же каталога), затем `cd ~/dekanat && docker compose up -d`. Без ключа помощник отвечает шаблонами по тем же положениям.

## Проверка перед подачей
- Открыть сайт с телефона через мобильный интернет без VPN.
- Войти тремя тестовыми аккаунтами, подать заявку, сменить её статус в кабинете учебного офиса.
- Подставить чужой номер заявки в адрес: должно быть «Страница не найдена».
