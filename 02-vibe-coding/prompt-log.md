## Ошибки ИИ и как их поймали
- **Чужая заявка отдавала код 200.** Страница показывала «не найдено», но статус ответа был 200, потому что общий экран загрузки включал потоковую отдачу. Поймал автотест на подмену адреса (Playwright). Исправление: экраны загрузки только у списков, теперь 404.
- **Сообщение «Готово» пропадало в кабинете офиса.** После закрытия заявки форма заменялась текстом «Заявка закрыта», и сотрудник не видел подтверждения. Поймал сценарный тест. Исправлено.
- **Политика безопасности ломала режим разработки** (React просит `eval` только в dev). Разрешили `unsafe-eval` только вне продакшена.
- **Стиль v3–v5 мешал читать** (замечание Роберта). Перешли к правилу «стекло только у навигации, цвет только для смысла».
- **Черновик заявления оставался в чате после отправки.** Скрываем черновик, если после него уже подана заявка.

## 10.11.2026, выкладка в Yandex Cloud: ошибки и как их нашли
- Поле «Метаданные» в веб-форме сохранило только первую строку cloud-init: машина поднялась пустой. Решение: создавать ВМ из Cloud Shell командой `yc ... --metadata-from-file`.
- В переданном user-data стёрлись выражения со знаком доллара: адрес в Caddyfile стал `{}`, Caddy падал. Нашли по логам из последовательного порта (диагностику дописали в cloud-init). Решение: адрес вписывается в файл командой sed, без переменных.
- Ошибка ИИ: сначала оценил цену ВМ в 800–1000 ₽/мес, реально 1483 ₽/мес (доля vCPU 20 % дороже, чем ожидалось).

## 10.11.2026, версия для компьютера и анимации
- Промпт Роберта (после первого захода на выложенный сайт): «Сделай мне имбовый моушен дизайн и исправь дизайн сайта для компов а то по бокам слишком пусто».
- Что сделал ИИ: от 1024 px нижняя панель превращается в стеклянное боковое меню, страницы «Сегодня», «Расписание», «Учёба», «Заявки» раскладываются в две колонки, неделя расписания идёт сеткой 3×2. Ошибки ИИ, которые он нашёл: помощник не знал про долг студента и отвечал «не нашёл»; слово «Сталинградская» считалось вопросом про Алину; в демо-данных стояли фиксированные даты, которые устарели бы к проверке.
