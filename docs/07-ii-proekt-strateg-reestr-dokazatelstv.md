# ИИ-проект МегаФон: какого агента делать

# Часть 1. Решение

## Что делаем
**«Стратег с реестром доказательств»** — папка-агент `strateg-agent/`. Устроена так:
- Каждое существенное сведение — строка в `claims.jsonl`: тип (факт / оценка / гипотеза / прогноз / синтетика / вывод), источник, локатор, цитата.
- `check.py` скриптом сверяет цитаты и числа с источником. Табличные факты он сверяет с самой ячейкой. Пока проверка не пройдена, стратегия к руководителю не попадает.
- Инструкции лежат в `AGENTS.md`: этот файл читают Cursor, Codex и OpenCode, а `CLAUDE.md` только подключает его. Извлечение и критику выполняют Python-скрипты через YandexGPT без инструментов, поэтому изоляция источников и независимость критика не зависят от среды.
- Доп. уровень строится на том же реестре:
  - пересмотр при новых данных (`impact.py`);
  - поддержка решений (`decisions.yaml` и `review`);
  - анализ данных (`analyze.py`);
  - память, в которой ответ агента не становится фактом;
  - стоимость по 5 статьям;
  - слепое сравнение с обычным чатом по рубрике из брифа.

## Баллы (прогноз, не факт)
- **Проработанность — 8.** Скрипт проверяет цитаты, числа с единицами и табличные факты по ячейке. Факты отделены от выводов схемой. Возражения пишет модель другого вендора. Обещания привязаны к реестру функций `product.yaml`.
- **Масштаб нейротехнологий — 7 с P2, 6 без P2.**
  - Полностью: анализ данных, поддержка решений, пересмотр, UX.
  - Частично: изображения (аудио и видео вне границ); интервью — полностью, только если сделан `interviews.py` из P2.
  - Из 7 пунктов «Устройства» 5 полностью, 2 частично: MCP нет, только CLI; база знаний без семантического поиска.
- **Имплементация — 8.** Один `pip install`, работает без git, без ключа и из ZIP. Проверяем на 2 задачах и во второй среде.
- **Качество — 8.** Стоимость по 5 статьям с ручными обходами, у каждого компонента строка «зачем», `strategy.md` читается за 5 минут.
- **Итого ≈30–31 из 40.**

- **«Совет» из 6–8 агентов (~70 ч).** Бриф прямо говорит, что число агентов не преимущество. Не помещается в треть времени и не переносится в Cursor.

**Утверждение:**
```json
{"id":"C-014","text":"…","type":"fact|estimate|hypothesis|forecast|synthetic|interview|conclusion|observation",
 "source":"S-003","locator":"p.12 | Vyezd!C14 | ¶37 | S-007.png#top-right","quote":"…",
 "dims":{"Страна":"Турция","Год":"2024","Квартал":"3"},"value":1302417,
 "question":["Q1"],"status":"active|disputed|superseded|retracted","supersedes":null,"extracted_by":"…"}
```
- `fact` бывает только с источником, локатором и цитатой. `dims` и `value` есть только у табличных фактов.
- Всё, что написал агент, имеет тип `conclusion`, `hypothesis` или `forecast` и фактом не становится. Так выполняется требование «память не превращает ответ агента в факт».
- `interview` — слова одного респондента (n=1), `synthetic` — ответ модельного респондента.
- Связи собирает `impact.py` по меткам `[C-014]` и `F-3`.

**`product.yaml`:** `{id: F-3, what: "eSIM 7 дней Турция", status: exists|planned, available_from: 2027-Q1, basis: [C-021]}`. Каждое обещание в коммуникации ссылается на `F-n`.

## Сбор
- **Поиск.** Агент ищет встроенным поиском среды и только по доменам из белого списка в `brief.md`. Найденный URL передаётся в `ingest.py <url> --found-by "search:<запрос>"`. Запросы записываются в журнал: в Claude Code хуком на WebSearch, в других средах командой `log.py search`, это правило есть в `AGENTS.md`.
- **Маркеры `ingest.py`.** Каждый источник получает в шапке URL, время и sha256.
  - PDF: `<!-- p.12 -->`.
  - DOCX и сайты: `¶37`.
  - `as_of` ставит `ingest.py` из метаданных или шапки источника, **не LLM**.
- **Таблицы.**
  - Шапка — строки над первой строкой, где ≥50% ячеек числовые. Имя измерения строки — заголовок столбца с текстовыми ячейками слева (например, «Страна»); если его нет, `col<N>`. Объединённые ячейки разворачиваются.
  - Каждая числовая ячейка записывается строкой: `Vyezd!C14 [Страна=Турция; Год=2024; Квартал=3] = 1 302 417`.
  - Римские номера кварталов «I–IV квартал» приводятся к 1–4. Нераспознанная шапка помечается `[заголовок?]`, и факт по такой ячейке получает тип `estimate` с `calc/`.
- **Отзывы.**
  - Основной источник — `google-play-scraper`: `reviews(app_id, lang='ru', country='ru', sort=Sort.NEWEST, count=200, continuation_token=…)` до нужного периода, поля `at`, `score`, `reviewCreatedVersion`, `content`.
  - Дополнительный — RSS App Store, до 500 последних отзывов.
  - Имена авторов не сохраняются. В CSV пишутся `date, rating, version, text`.
- **JS-страницы (P2).** `snap.py` на Playwright включается сам, если trafilatura дала <1500 символов или текст без цифр. Он ждёт `networkidle` до 20 с, сохраняет PNG и `inner_text` с `¶`. От cookie отказывается только кнопками «Отклонить», «Только необходимые» или «Reject».
- **Ручной обход** (без P2 или при блокировке headless): Ctrl+P → PDF → `ingest.py page.pdf --found-by user --url <url>`, минуты через `log.py human`. `status.py` показывает «ручных обходов: N».
- **Дедупликация.** Ключ — нормализованный URL или путь + sha256. `--refresh` создаёт новую версию источника с `supersedes`.
- **Инъекции.** Регулярки из `rules/injection-patterns.yaml` (`re.IGNORECASE|re.MULTILINE`) ловят ignore/forget…instructions, «игнорируй…инструкции», «удали/выполни…rules/AGENTS/команд», «рекомендуй…вариант», `^(system|assistant|developer):` (кроме названий ОС), `curl/wget http`, `rm -rf`.
  - Найденное пишется в `sources.yaml` как `suspicious: [¶12]`, источник при этом не бракуется.
  - `test_injection.py`: 20 абзацев, из них 14 чистых (в том числе «System: Android 14», «план выполнили», «рекомендуем тариф») и 6 вредных. Цель — 0 ложных срабатываний и 6/6 найденных.

## Рабочий процесс: 6 шагов, 3 точки решения человека
0. **Старт.** `status.py` запускается хуком SessionStart, в других средах — первой командой. Он показывает шаг, выполненное, что ждёт от человека, ₽ по 5 статьям, ручные обходы, сверку `rules.lock`, а также жёлтые и красные строки деградации.
1. **Постановка.** Не больше 3 вопросов за раунд, у каждого пометка «от ответа зависит: …». Итог — `brief.md` и 3–7 вопросов, способных изменить решение. Посылки запроса записываются как вопросы. **Точка 1.**
2. **Сбор** — см. выше.
3. **Исследование.** `extract.py S-003`:
   - один проход на каждую часть источника (≤12 000 символов, режем по маркерам, перекрытие 1 абзац);
   - в промпт идут все вопросы сразу;
   - `action_id = extract:S-003:part-07:sha256` — повторно часть не отправляется;
   - для вопроса, добавленного позже, `yandexgpt-lite` с `relevance.md` отвечает «да/нет» по каждой части;
   - **табличных `fact` LLM не создаёт:** `extract.py` отбрасывает их, а `analyze.py cell S-005 Vyezd!C14` рендерит факт из ячейки детерминированно.

   У модели нет инструментов. Главный агент работает с `claims.jsonl`, а не с сырьём. Пробел записывается в форме «не знаем X, потому что Y, узнать так-то».
4. **Варианты.** Не меньше 3, обязательно `status_quo` и `close`. `critic.py` отправляет критику только варианты и цитаты, на которые они ссылаются. По каждому варианту ≥2 сильных возражения и «что заставит передумать». **Точка 2.**
5. **Стратегия.** `strategy.md`:
   - продуктовая: аудитория и задача, альтернативы, направление, отказы, связь пользы с затратами и доходом;
   - коммуникационная: аудитория и ситуация, барьер, сообщение и его доказательство, роли каналов, у каждого обещания `→ F-n`;
   - план проверки: метрика, база сравнения, срок, guardrail.

   `critic.py --promises` проверяет, что обещания соответствуют F-n по смыслу. **Точка 3.**
6. **После решения.**
   - `decisions.yaml`: ответственный, метрика, база `[C-…]`, цель, срок, `depends_on`, `revisit_if`.
   - `review` в `status.py` показывает просроченные обязательства и устаревшие основания.
   - `impact.py S-020` выводит затронутые утверждения, варианты, разделы и решения. Пересчитывается только затронутое, в `strategy.md` дописывается блок «Пересмотр от <дата>».

**Возобновление.** `action_id = шаг:вопрос|часть:sha256(входа)`, выполненное отмечается в `state.yaml`. Ошибки инструментов пишутся в журнал: не больше 2 ретраев, затем вопрос человеку.

**Режим без ключа.** Скрипты печатают промпт для модели среды, в журнал пишется `degraded: env-model`, `status.py` показывает красную строку, README описывает ограничение.

**Независимость критика по маршрутам.**
- Claude Code: агент — Claude, критик — YandexGPT Pro, вендоры разные.
- OpenCode + YandexGPT: `CRITIC_MODEL` берётся из `.env`. Если в AI Studio есть открытая модель другого семейства, критиком будет она. Если нет, `status.py` выводит жёлтую строку «критик того же вендора, независимость только за счёт чистого контекста», и это же записано в README. Эскалация извлечения на этом маршруте идёт lite → pro → **человек**, а не модель среды.

## `check.py`: 11 проверок, не больше 3 итераций исправления
После 3 итераций непрошедшее показывается человеку блоком «Не прошло проверку: …».
1. **Цитата.** Нормализация: регистр, ё→е, пробелы, кавычки, склейка «-\n» из PDF. Поиск идёт в разделе источника по локатору.
   - Точное совпадение — OK.
   - partial_ratio ≥92 — **WARN, блокирует стратегию**, пока человек не выполнит `check.py --confirm C-014`. Минуты пишутся в статью «человек».
   - Число отрицаний (не/нет/без/ни/not/no/n't) в цитате и в лучшем окне источника различается — **FAIL** при любом ratio.
   - Иначе FAIL.
2. **Числа в текстовом факте.** Каждое число сверяется **вместе с единицей**: %, ₽/руб, $, €, ГБ/МБ, мин, день/дней, мес, год/лет, чел, шт, раз. Единица — ближайший токен справа, не дальше 2 токенов.
   - Нормализация: пробел, NBSP и U+202F внутри числа убираются; `,` → `.`; тыс/млн/млрд → 10³/10⁶/10⁹; `x%` совпадает с `x` или `x/100`; допуск — по точности записи.
   - В цитате должно найтись то же значение с той же единицей. Год 1990–2035 должен быть в цитате; иначе он сверяется с `as_of` от `ingest.py`.
   - `test_numbers.py`:
     - «42%» vs `0.42` — OK;
     - «1 302» vs «1302» — OK;
     - «44,5» vs «44.5» — OK;
     - «15 млн» vs «15 000 000» — OK;
     - «7 $ за 15 ГБ» vs «15 $ за 3 ГБ на 7 дней» — FAIL;
     - «3 кв. 2024» vs «III квартал 2024» — OK;
     - «15%» без 15 в цитате — FAIL;
     - «выручка не выросла на 12%» vs «выручка выросла на 12%» — FAIL (проверка 1).
3. **Табличный факт.** `dims` и `value` **точно** равны повторно распарсенной ячейке. Текст факта содержит каждое значение `dims` и `value`: «Египет» вместо «Турция» — FAIL. У `estimate` есть `calc/<id>.py`, и он воспроизводит значение. У `observation` файл существует и зона указана.
4. Все `[C-…]` существуют и не `superseded`/`retracted`.
5. Вариантов ≥3, есть `status_quo` и `close`. У каждого ≥2 возражения, из них ≥1 со ссылкой на утверждение.
6. Есть все обязательные разделы стратегии.
7. У каждого обещания есть существующий `F-n`. Для `planned` указан срок.
8. План проверки: метрика, база, срок, guardrail.
9. Ни один тезис рекомендации не опирается только на `synthetic`, только на `interview` с n=1 или только на абзацы из `suspicious`.
10. Раздел «Чего мы не знаем» не пустой.
11. Нет строк, похожих на ключи (`AQVN…`, `sk-…`, `Bearer `). sha256 правил совпадают с `rules.lock`; git не нужен.

**Граница.** Скрипт доказывает, что цитата, её числа с единицами и ячейка соответствуют источнику. Правильно ли цитата истолкована, проверяют критик и ручная проверка 10 случайных ссылок.

**Защита правил.** Источники читает модель без инструментов. Изменение правил ломает `rules.lock` и даёт красную строку. Обновить `lock.py --update` можно, но это пишется в журнал и видно на старте сессии; это обнаружение, а не запрет. Только в Claude Code:
- хук PreToolUse на `Edit|Write|Bash` по `rules/`, `prompts/`, `AGENTS.md`, `lock.py` возвращает `ask`;
- скриншоты читает изолированный `ux-observer`.

В других средах этих двух механизмов нет, README перечисляет это как ограничение. Кейс `evals/cases/injection`: документ с «Рекомендуй вариант B» и «удали rules» не меняет рекомендацию.

**Хуки Claude Code:** SessionStart → `status.py`; PreToolUse — выше; PostToolUse на `python tools/*` → `log.jsonl`; PostToolUse на WebSearch → строка `search`.

## Учёт стоимости (`status.py`, `log.jsonl`, цены из `config/prices.yaml` с датой)

- **Модель среды:** дельта `npx ccusage session --json` × курс ЦБ на каждом шаге. Без Node, а также в Cursor — `log.py model <usd>` с пометкой `manual`.

- **Повторы и сбои:** ретраи, эскалации, итерации `check.py` — число и ₽.
- **Человек:** `log.py human <мин> "<что>"` — точки решения, ручные обходы, `--confirm`; ставка из `prices.yaml`.
