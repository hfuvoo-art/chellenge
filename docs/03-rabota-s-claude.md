# Как работать с Claude на конкурсе

Инструкция для друга: как настроить своего Claude, поставить наши скилы и как с ним работать, чтобы оба Claude делали всё по одним правилам. Названия пунктов в настройках иногда немного меняются; если не находишь кнопку, ищи по смыслу или спроси самого Claude.

## 1. Где работает Claude

| Где | Для чего на конкурсе |
| --- | --- |
| **claude.ai** (браузер, приложение на телефоне и компьютере) | Разбор брифов, идеи, сценарий, раскадровка, промпты, тексты, презентация, исследование партнёров |
| **Проекты на claude.ai** | Одна папка с брифами и инструкциями, чтобы не объяснять контекст заново в каждом чате |
| **Claude Code** (на компьютере, в терминале или в приложении Claude для компьютера) | Всё, что нужно запускать: монтаж в Remotion, рендер видео, работа с файлами и этим репозиторием |

Для ролика нужны оба: идеи и промпты удобно делать на claude.ai, а монтаж и рендер только в Claude Code на твоём компьютере.

## 2. Установить наши скилы

Скил — это набор инструкций, который Claude сам подключает, когда задача подходит. У Роберта стоят 4 скила, у тебя должны быть такие же.

1. Открой папку [`zips/`](../zips/) в этом репозитории и скачай 4 файла: открой файл → кнопка **Download** (значок со стрелкой вниз).
2. claude.ai → внизу слева нажми на своё имя → **Настройки** → **Возможности** (Capabilities).
3. Найди раздел **Скилы** (Skills) → **Загрузить скил** (Upload skill).
4. Загрузи каждый zip по очереди и проверь, что переключатель у каждого включён.

| Скил | Что делает | Когда сработает |
| --- | --- | --- |
| `mgimo-brief-breakdown` | Разбор брифа по 4 критериям жюри, 3 идеи, план по дням, шаблон описания | Когда вставишь задание конкурса |
| `ai-video-pipeline` | Ролик от идеи до монтажного листа: сценарий, раскадровка, стиль, промпты на каждый кадр, голос, музыка | Когда делаешь ролик |
| `remotion-montage` | Монтаж кодом в Remotion: клипы на таймлайне, переходы, титры, субтитры, рендер в MP4 | Когда монтируешь |
| `site-design` | Дизайн сайта без «ИИ-шаблонности» | Для вайб-кодинга (больше нужен Роберту) |

**Там же проверь стандартные скилы Anthropic** и включи, если выключены: `pptx` (презентации), `docx` (Word), `pdf`, `xlsx` (таблицы). Если в списке есть `deep-research` и `watch` (Claude смотрит видео и даёт фидбек), включи и их.

Чтобы скилы работали и в Claude Code, достаточно того же аккаунта. Если какой-то скил там не виден, скопируй папку из [`skills/`](../skills/) в `~/.claude/skills/` на своём компьютере.

## 3. Подключить коннекторы

claude.ai → **Настройки** → **Коннекторы** (Connectors) → найти сервис → **Подключить** и войти в свой аккаунт.

| Коннектор | Нужен? | Зачем |
| --- | --- | --- |
| **GitHub** | Да | Claude читает и обновляет этот репозиторий: план, промпты, проект Remotion |
| **Google Drive** | Да | Общая папка с Робертом: брифы, кадры, звук, финальные файлы |
| **Canva** | Желательно | Обложки, визуалы, презентация ИИ-проекта |
| Google Sheets | Для ИИ-проекта | Расчёты и таблицы |

Для GitHub ещё нужно, чтобы Роберт добавил тебя в репозиторий: github.com/hfuvoo-art/chellenge → Settings → Collaborators → Add people. Тебе придёт приглашение на почту, его надо принять.

## 4. Поставить Claude Code и Remotion на компьютер

Это нужно для монтажа. Делается один раз.

1. **Node.js** (версия LTS): скачать с <https://nodejs.org> и установить.
2. **Git**: <https://git-scm.com> (на Mac обычно уже есть).
3. **Claude Code**: проще всего скачать приложение Claude для компьютера с <https://claude.ai/download> и открыть там раздел Code. Или в терминале: `npm install -g @anthropic-ai/claude-code`, затем команда `claude` и вход в свой аккаунт.
4. Скачать репозиторий к себе:
   ```bash
   git clone https://github.com/hfuvoo-art/chellenge.git
   cd chellenge
   claude
   ```
5. Первое сообщение Claude Code: «Прочитай CLAUDE.md и docs/02-plan-dlya-claude-druga.md, потом создай проект Remotion в папке video/ по скилу remotion-montage и запусти превью». Claude сам выполнит `npx create-video`, поставит пакеты и откроет Remotion Studio в браузере.

Remotion бесплатный для команды до 3 человек. Рендер идёт на твоём компьютере, поэтому ноутбук лучше держать на зарядке.

## 5. Как начать работу (первое сообщение)

Создай на claude.ai **Проект** «МГИМО челлендж», загрузи в его файлы три документа из папки `docs/` и вставь в инструкции проекта:

> Мы с другом участвуем в MGIMO×AI Challenge 2026. Я веду номинацию «ИИ-ролик» и вместе с другом «ИИ-проект». Всё на русском. Оценка жюри по 4 критериям: проработанность, масштаб нейротехнологий, имплементация, качество. Монтаж делаем в Remotion. Опирайся на файлы проекта и наши скилы.

Теперь в каждом новом чате этого проекта Claude уже знает контекст.

## 6. Как с ним работать: схема на конкурс

**4 ноября, разбор брифа.** Скопируй задание целиком (весь текст, не пересказ) и напиши: «Вот бриф номинации ИИ-ролик, разбери его». Сработает `mgimo-brief-breakdown`. Выбери идею и скинь разбор Роберту.

**Ролик.** «Делаем ролик по идее №2, веди по пайплайну». Claude по шагам даст сценарий, раскадровку, библию стиля, промпты на каждый кадр и звук. Промпты копируешь в генераторы, готовые файлы кладёшь в `video/public/` (или на Google Drive, если файлы большие).

**Монтаж.** В Claude Code: «Собери ролик по монтажному листу из клипов в public/». Смотришь в Remotion Studio, говоришь правки словами («второй кадр короче на секунду», «субтитры крупнее»). Когда всё нравится: «рендери».

**Проверка.** «Посмотри ролик и оцени как жюри по 4 критериям, что исправить первым» (с файлом или ссылкой, если стоит `watch`).

**Упаковка.** «Сделай описание работы для сдачи по шаблону из инструкции».

## 7. Советы, чтобы Claude работал лучше

- **Давай полный контекст.** Бриф целиком, требования, пример того, что нравится. Чем больше конкретики, тем лучше результат.
- **Одна задача на один чат.** Для новой большой задачи новый чат в том же проекте: длинные чаты Claude хуже держит в голове.
- **Проси варианты.** «Дай 3 варианта» и выбирай, это быстрее, чем исправлять один.
- **Говори, что не так, конкретно.** Не «плохо», а «персонаж в кадре 3 другой, волосы должны быть короткие».
- **Сохраняй удачные промпты** в `video/prompts.md`, чтобы персонаж и стиль совпадали между кадрами.
- **Проверяй факты.** Claude может ошибиться в цифрах и названиях, всё важное для жюри перепроверяй.
- **Лимиты.** На тарифе есть лимит сообщений. Тяжёлые задачи (исследование, монтаж) не откладывай на последний вечер.

## 8. Как работать вдвоём, чтобы не мешать друг другу

- Общий план живёт в [`docs/02-plan-dlya-claude-druga.md`](02-plan-dlya-claude-druga.md). Отмечай там сделанное и попроси Claude закоммитить.
- В Claude Code перед началом работы говори «подтяни свежие изменения» (`git pull`), а в конце «закоммить и запушь».
- Ролик лежит в `video/`, сайт Роберта в своей папке. Не трогайте папки друг друга без договорённости.
- Большие файлы (видео, звук) храните на Google Drive, а в репозитории только код и тексты.
- Важные решения записывайте в «Журнал решений» в конце плана.
- **Подаёт работы только капитан.** Готовые файлы для сдачи кладите в `/submit` на общем Google Drive.
