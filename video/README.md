# Ролик «Самый спелый гранат» (Tonka, Smoky Pomegranate)

Пробная версия: сценарий, промпты и аниматик в Remotion. Вместо ИИ-клипов пока цветные заглушки с описанием кадра, титры и тайминг уже настоящие.

- `scenariy/01-scenariy-i-raskadrovka.md`: идея, драматургия, раскадровка на 13 сцен, 80 секунд.
- `scenariy/02-promty.md`: библия стиля, промпты картинки и видео на каждый кадр, голос, музыка, звуки.
- `src/scenes.ts`: таймлайн. Сюда вписываем имена готовых клипов, звука и логотипа.

## Как запустить

```
cd video
npm i
npm run studio     # превью в браузере
```

## Как подменять заглушки

1. Сгенерированный клип кладём в `public/clips/` (например `04-sok.mp4`).
2. В `src/scenes.ts` у нужной сцены пишем `clip: '04-sok.mp4'`.
3. Так же голос, музыка и звуки (`public/audio/`, массивы `VOICE`, `MUSIC`, `SFX`) и логотип (`public/brand/`, `LOGO`).

Медиафайлы в git не коммитим, они лежат на Google Drive.

Рендер MP4 (`npm run render`) только по команде.
