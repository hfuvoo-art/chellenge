Репозиторий команды на [MGIMO×AI Challenge](https://challenge.mgimo.ai): инструкции, план и скилы для Claude. Задания выходят 4 ноября 2026 в 12:00 МСК, приём работ до 22 ноября 23:59.

## Скилы

| Скил | Для чего |
| --- | --- |
| `mgimo-brief-breakdown` | Разбор брифа партнёра по 4 критериям жюри, 3 идеи и план работ |
| `ai-video-pipeline` | Ролик: сценарий, раскадровка, промпты на каждый кадр, звук, монтажный лист |
| `remotion-montage` | Монтаж ролика кодом в Remotion: клипы, переходы, титры, субтитры, рендер |
| `site-design` | Дизайн сайта без «ИИ-шаблонности» (копия скила frontend-design от Anthropic) |

## Как установить

1. Скачай нужные zip из папки [`zips/`](zips/) (файл → кнопка Download).
2. claude.ai → Настройки → Возможности (Capabilities) → Скилы → «Загрузить скил».
3. Загрузи каждый zip по очереди.

Исходники лежат в [`skills/`](skills/), по одному `SKILL.md` на скил.

Также проверь, что включены стандартные скилы: pptx, docx, pdf, xlsx, deep-research.
