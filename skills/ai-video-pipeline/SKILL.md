# Пайплайн ИИ-ролика

Жюри смотрит на идею, сторителлинг, картинку и звук, а оценивает по 4 критериям: проработанность, масштаб нейротехнологий, имплементация, качество.

## Шаги

1. **Требования.** Выпиши из брифа: длительность, формат (16:9 / 9:16), язык, обязательные элементы бренда, файлы для сдачи. Если чего-то нет, предложи вопрос организаторам.
2. **Идея.** Три концепции одной фразой, с эмоцией и инсайтом аудитории. Выбери одну вместе с пользователем.
3. **Сценарий.** Структура: крючок за первые 3 секунды, развитие, поворот, бренд и призыв. Тайминг по секундам. Закадровый текст отдельно.
4. **Раскадровка.** Таблица: № кадра, секунды, что в кадре, движение камеры, переход, звук.
5. **Единый стиль.** Опиши «библию» стиля: палитра, свет, объектив, эпоха, описание главного героя одной неизменной фразой, чтобы персонаж совпадал между кадрами.
6. **Промпты.** На каждый кадр: промпт для картинки-референса (image-to-video даёт стабильнее результат) и промпт для видеогенератора с движением камеры. Давай 2 варианта на сложные кадры.
7. **Звук.** Текст для синтеза голоса с паузами и ударениями, промпт для музыки (жанр, темп BPM, настроение), список SFX.
8. **Монтажный лист.** Порядок клипов, обрезка, титры и субтитры, цветокор, финальная плашка бренда. Если стоит плагин Remotion, предложи собрать титры и сборку кодом.
9. **Проверка.** Если стоит скил watch, посмотри черновик ролика и дай фидбек как жюри по 4 критериям.
10. **Описание для сдачи.** Какие нейросети на каком шаге (это поднимает критерий 2), ключевые промпты, как бренд может использовать ролик.

## Правила
- Держи стиль и персонажа одинаковыми во всех кадрах.
- Не используй чужие товарные знаки и реальных людей без брифа.
- Пиши по-русски и просто.
