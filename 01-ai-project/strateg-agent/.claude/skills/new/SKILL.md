# Новый проект

1. Если человек не дал запрос — спроси одним вопросом: «Какой вопрос или решение нужно проработать?». Запрос уже есть («Новый проект: …») — не переспрашивай.
2. Если `.venv` нет или скрипты пишут «Библиотеки агента не установлены» — сначала «Первое действие» из `AGENTS.md` (установка одной фразой, после «да»).
3. Придумай имя из латиницы, цифр, «-» и «_» и выполни `python tools/project.py new <имя>`.
4. Прочитай `playbooks/1-frame.md` и выполняй его: он — единственный источник истины для шага 1. Не пересказывай из памяти.
5. Сообщения начинай строкой прогресса, ожидание ответа — строкой «Ваш ход: …» (`AGENTS.md`).
