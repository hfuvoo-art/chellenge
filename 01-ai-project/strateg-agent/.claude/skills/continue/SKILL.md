# Продолжить с сохранённого места

Выполни раздел «Продолжение после перерыва» из `AGENTS.md`: «Первое действие» (проект, `python tools/lock.py --verify`), затем `python tools/status.py`, `state.yaml` (`step`, `waiting`, `done`), `brief.md`, последние строки `log.jsonl`, playbook текущего шага (`playbooks/N-….md`). Не начинай заново и не повторяй действия из `done`. Незакрытое `waiting` — сначала верни человеку этот вопрос.

Начни ответ со строки прогресса (`Шаг N из 6 · …`), закончи строкой «Ваш ход: …».
