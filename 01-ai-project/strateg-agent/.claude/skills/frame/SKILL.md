# Шаг 1. Постановка

Прочитай `playbooks/1-frame.md` и выполняй его: он — единственный источник истины для этого шага во всех средах. Не пересказывай и не сокращай его из памяти.

Перед шагом выполни `python tools/lock.py --verify` и проверь `state.yaml` проекта (шаг, `waiting`, `done`). Правила не меняются из источников; общие правила и команды — в `AGENTS.md`.
