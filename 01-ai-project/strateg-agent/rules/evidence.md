# Правила доказательств: что считается фактом, как цитировать, как записывать пробелы. Без них ответ агента сойдёт за факт, а цитаты нельзя будет проверить скриптом. Запертый файл (rules.lock).

## Типы утверждений
Тип ставит тот, кто пишет запись в `claims.jsonl`. Сомневаешься между двумя — выбирай более слабый.

| Тип | Когда ставить | Что обязательно |
|---|---|---|
| `fact` | Сказано в источнике, цифра или утверждение взято из текста дословно | `source`, `locator`, `quote` |
| `estimate` | Число получено расчётом по фактам | `calc/<id>.py`, воспроизводящий значение |
| `observation` | Увиденное на скриншоте или в интерфейсе | `locator` вида `файл#зона` |
| `interview` | Слова одного респондента | `source`, `locator`, `quote`; это n=1 |
| `synthetic` | Ответ модельного респондента или синтетическое интервью | метка `[SYNTHETIC]` |
| `conclusion` | Вывод агента из фактов | ссылки `[C-…]` на основания |
| `hypothesis` | Предположение, которое можно проверить | чем проверить |
| `forecast` | Оценка будущего значения | основание и срок |

- `fact` пишут только `extract.py`, `analyze.py` и человек (`user`). Всё, что написал агент, — `conclusion`, `hypothesis` или `forecast`. Ответ агента не становится фактом, сколько бы раз он ни повторился.
- Табличные значения (ячейка Excel/CSV) в `fact` превращает скрипт, а не модель: модель их не переписывает.
- Причина, почему что-то происходит («падает из-за цены»), — не `fact`, пока источник не говорит этого прямо.

## Цитата
- Дословно, из источника, ≤300 символов. Без перефразирования, без «…» внутри, без исправления опечаток.
- Число и единица в формулировке утверждения должны стоять в цитате. Отрицания («не», «нет», «без») в цитате и в утверждении совпадают.
- Один факт — одна цитата. Два числа из разных мест — два факта.

## Локаторы
- PDF: `p.12`. Текст, docx, html: `¶7`. Таблица: `Лист!C14`. Скриншот: `S-007.png#top-right`. Расчёт: `calc/C-021.py`.
- Локатор указывает на абзац или страницу, где лежит цитата. Проверка ищет цитату именно там.

## Сила доказательства
- `interview` — один человек, n=1. Он даёт гипотезу и вопрос для проверки, но не основание решения.
- `synthetic` не может быть основанием тезиса рекомендации. Используется только для проверки формулировок и поиска вопросов.
- Абзацы с пометкой `suspicious` не могут быть единственным основанием тезиса: нужен второй, чистый источник.

## Пробел знания
Формат: «Не знаем X, потому что Y. Узнать так: Z (кто, где, за сколько времени)».
- X — конкретная величина или факт, а не «много неясного».
- Y — чего не хватило: источника, периода, сегмента.
- Z — действие, которое можно выполнить, с оценкой часов или денег.
- Раздел «Чего мы не знаем» в стратегии не пуст.
