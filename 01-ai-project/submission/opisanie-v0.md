# Стратег с реестром доказательств — описание (v0, страховочная подача)

Статус: промежуточная версия после КТ-A (13.11.2026). Демо — на нашей задаче №1 (eSIM для поездок россиян), демо-бриф МегаФона ещё не вышел. Стратегия демо не финальная: аудит нашёл в ней содержательные ошибки, они исправляются. Репозиторий: https://github.com/hfuvoo-art/strateg-agent [нужны данные: ссылка рабочая после заливки, доступа пока нет].

Источники чисел: **[Ж]** `01-ai-project/build-log.md`; **[С]** `python tools/status.py -p esim-travel`; **[П]** `projects/esim-travel/check-report.md`; **[А]** `notes/jury-audit-ai-project-K-KT-A.md`.

## Архитектура
Папка для Claude Code (вторая среда OpenCode — не проверена). `AGENTS.md` — роль и процесс: 6 шагов, 3 точки человека, 6 playbooks. Знания раздельно: `rules/`+`prompts/` (заперты `rules.lock`), `methods/` (8 методик), `projects/<имя>/` (материалы, реестр `claims.jsonl`, `state.yaml`, `log.jsonl`). Ядро — реестр: факт = источник + локатор + дословная цитата, проверяют скрипты `tools/check.py` (11 проверок), не модель. Продолжение после перерыва — `state.py`/`status.py`.

## Модели, сервисы, инструменты
- Модель среды (Claude Code) ведёт процесс и пишет выводы.
- Alice AI LLM Flash — извлечение: точнее YandexGPT Pro 5.1 (72 % против 59 % точных цитат, 3 части) и в 4 раза дешевле [Ж, спайк 09.11].
- YandexGPT Pro 5.1 — эскалация и критик другого семейства.
- Веб-поиск Claude, `ingest.py` (xlsx, PDF, сайты, отзывы без ПДн), `analyze.py`, `export.py` (HTML/DOCX), 4 хука Claude Code.

## Ключевые промпты
`prompts/extract.md` (только дословные цитаты), `critic.md`, `critic-promises.md`, `critic-claims.md`, `respondent.md` (синтетика, помечается). Правила — `rules/`.

## Возможности доп. уровня (как доказано)
- Маршрутизация и сбои — доказано на демо: 1 эскалация lite→pro, 2 ремонта JSON, повтор из кеша без вызовов [С; А].
- Анализ данных — частично: 11 табличных фактов, `calc/` воспроизводится; `profile` нет [А].
- Модельные респонденты, хуки/навыки, база знаний (отзыв и спор записей) — частично; на демо респонденты не запускались [А].
- Не реализовано или не показано: поддержка решений, пересмотр при новых данных, UX/изображения, переносимость, сравнение с чатом [А] (в плане задач 17–19).
