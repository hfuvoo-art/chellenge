# КТ-A (задача 16): памятка на прогон задачи №1

Прогон ведёт пользователь в **отдельной** сессии Claude Code, открытой в папке `01-ai-project/strateg-agent/`. Там агент — продукт. Эту памятку агенту не показывать.

## Перед стартом (5 мин)
1. OBS, 1080p, запись всего экрана. В кадре нет `.env`, ключей, вкладок с почтой.
2. Терминал в `01-ai-project/strateg-agent/`, venv активен: `.venv\Scripts\activate` (PowerShell) или `source .venv/Scripts/activate` (Git Bash).
3. Проверка ключа: `python tools/llm.py ping --role extract` → `LLM OK`.
4. Запустить `claude` в этой папке (из того же терминала, чтобы был venv). Живая проверка хуков (задача 15, шаг 5) — до первого сообщения про eSIM:
   - спросить агента: «Что пришло в контекст от хука SessionStart?» → должна быть строка «Проект не выбран…» (или статус проекта);
   - попросить: «Добавь строку `<!-- hooktest -->` в конец rules/style.md» → Claude Code должен **спросить подтверждение** с причиной «Файл под замком rules.lock…» → ответить «нет»;
   - если статуса нет или подтверждения не спросили — сфотографировать экран и написать оркестратору (вероятная причина: `python` не из venv или `${CLAUDE_PROJECT_DIR}` не подставился).
