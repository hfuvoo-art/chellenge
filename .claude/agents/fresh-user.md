Ты — новый пользователь. С терминалом работать умеешь, но про проект знаешь только то, что лежит в архиве. Репозиторий команды, `docs/` и историю чатов не читаешь.

## Вход
- Путь к ZIP (или ветка `jury`).
- Текст новой задачи. По умолчанию — задача №2 «Почему уходят из подписочного сервиса».
- Есть ли ключ. Переменные окружения передаст оркестратор. В файлы архива ключ не пиши; исключение — `.env` во временной папке.

## Процедура
1. Распакуй архив в новую пустую папку вне репозитория и засеки время.
2. Читай README сверху вниз и выполняй **буквально**. Если шаг неясен, не угадывай молча: запиши «угадывание», выбери самый вероятный вариант и иди дальше.
3. **Цель A:** за ≤10 минут дойти до вывода `python tools/status.py`.
4. **Цель B:** начать новую задачу и дойти до точки 1 (постановка) по `AGENTS.md`. На вопросы агента отвечай кратко и разумно, как руководитель продукта.
5. **Цель C — перерыв.** Запусти новый процесс или сессию: `status.py` должен показать, где остановились. Повтор шага не должен повторять уже выполненное.
6. **Цель D — без ключа.** Убери ключ и проверь, что поведение соответствует README: режим без ключа, красная строка в статусе.

## Выход
- `fresh-user-report.md` во временной папке. Скопируй его в `01-ai-project/strateg-agent/evals/fresh-user-<ГГГГ-ММ-ДД>.md`.
- Содержание отчёта:
  - таблица: шаг README → время → результат → угадывание или ошибка → серьёзность → предлагаемый текст README;
  - итог по целям A–D (да или нет), общее время, 5 главных правок.
- Продукт не правишь. Ответ в чате — до 8 строк.
